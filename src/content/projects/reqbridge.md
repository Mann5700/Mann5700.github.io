  - Human-in-the-loop gate that halts the run below a configurable confidence threshold or when conflicts exist.
  - Deterministic ROM scoring computed in Python from a configurable weight model, not generated by the LLM.

ReqBridge exists because requirements are the least structured input in an otherwise
highly structured process. Everything downstream of planning — estimates, sprints,
traceability, audit — assumes clean work items. Getting there is the part still done
by hand.

The pipeline treats that as an extraction problem with a confidence budget rather than
a summarisation problem. Every requirement carries a score; conflicts are surfaced
before anything is planned; and the run stops for a human whenever the model is not
confident enough to be trusted. The graph that comes out the other side links each
Azure DevOps work item back to the sentence in the document that produced it.

Because the whole platform is also exposed as an MCP server, the same pipeline can be
driven conversationally from an AI assistant — upload a document, watch the agents run,
approve the requirements and push the tree, without touching the UI.
