I'm a software engineer at UPS, where I build the internal tools other engineering
teams run on — **AI agents, data pipelines and automation** that remove work nobody
should be doing by hand.

Before that I finished a Master's in Computer Science at NYIT with distinction, and
spent a summer at Apixio building a React platform for reviewing hundred-thousand-record
patient datasets. My first degree was in Mechanical Engineering, which is probably why
I still think about software the way I think about machines — *tolerances, failure modes
and moving parts*.

Most of what I build follows the same shape: find a process that quietly costs a team
hours every sprint, understand it properly, then remove it. Sometimes the answer is a
multi-agent LLM pipeline. Sometimes it's a Python script with a thread pool. Deciding
which is the actual engineering.

Away from the keyboard I'm an astrophotographer, which is the same job with worse hours —
pulling a faint signal out of a very noisy sky.
